# Skill template

Starting point for a new skill. Do not edit this in place; copy it with:

```bash
python3 scripts/new_skill.py my-skill-name
```

The script copies `SKILL.md` into `skills/my-skill-name/`, fills in the name,
and reminds you to write the description. Optional sub-directories
(`references/`, `scripts/`, `assets/`) are created on demand, not by default.
