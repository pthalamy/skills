# Skills

Each sub-directory here is one skill and must contain a `SKILL.md` with at least
`name` and `description` in its YAML frontmatter. The directory name and the
`name` field must match.

Create a new one with `python3 scripts/new_skill.py <skill-name>` and check
everything with `python3 scripts/validate_skills.py`.

The root `README.md` holds the human-readable index of skills. Keep it in sync
when you add or remove a skill.
